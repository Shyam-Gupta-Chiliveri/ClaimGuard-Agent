Real and simulated

Real Every district, country and fraud figure comes from a published source or is calculated from one.

Simulated The 800 claims in the triage inbox and the live stream. Claim-level data is confidential, so claims are generated with a fixed seed and labelled as simulated wherever they appear.

The triage numbers therefore describe how the system behaves. They are not fraud detection rates.

How the numbers are produced

Regionalklasse model

Predicts the GDV class of a district from public accident, fleet and population features. A median baseline, a ridge regression and gradient boosting are compared. Validation groups districts by Bundesland, so every prediction is for a state the model has not seen. A random split is reported only to show how much it overstates accuracy.

District explanation

Each feature of a district is replaced by the German median in turn. The change in the predicted class is that feature's contribution.

Claim triage

Ten published red-flag indicators add points. The total sets the band: green 0 to 14, amber 15 to 34, red 35 and above. An Isolation Forest scores how unusual a claim is. A green claim it flags is routed for a second look. It is a second opinion, not a fraud classifier, because no real fraud labels exist.

Drift

The Population Stability Index compares each fleet feature in the KBA 2026 data with the 2025 data the model was trained on. Above 0.10 is watched, above 0.25 calls for a retrain.

Agent

The agent chooses among twelve tools over the data marts, the models and a keyword index of the source documents. Without a language model it uses a deterministic planner that calls the same tools.

Limits

  • The Unfallatlas records accidents with personal injury only. Property-damage claims, which make up most motor liability claims, are not in public data.
  • GDV sets classes from insurers' claims experience. Public data explains part of that, so the model is a tool for explanation and for finding gaps, not a replacement for the GDV classes.
  • Last year's class predicts this year's class far better than any public-data model. That benchmark is shown in the ML lab.
  • KBA reports Trier and Trier-Saarburg as one figure, so both districts have no fleet features.
  • National fraud figures use different definitions and are shown side by side, never ranked.
  • EIOPA claims ratios cover all non-life business, not motor alone.

Glossary of German terms

Regionalklasse
Regional risk class. GDV assigns one to every registration district each year from the claims experience of the vehicles registered there. A higher class means a higher regional component of the premium. The classes are a recommendation, not binding on insurers.
Kfz-Haftpflicht
Compulsory motor third-party liability insurance. Classes 1 to 12.
Vollkasko
Comprehensive cover, including damage to the insured's own car in an at-fault accident. Classes 1 to 9.
Teilkasko
Partial cover: theft, glass, storm, hail and collisions with animals. Classes 1 to 16.
Bundesland
One of the 16 federal states.
Kreis, kreisfreie Stadt
District and independent city, the 400 units used here. AGS is the official five-digit district key.
GDV
Gesamtverband der Deutschen Versicherungswirtschaft, the German insurance association.
KBA
Kraftfahrt-Bundesamt, the federal motor transport authority.
Destatis
Statistisches Bundesamt, the federal statistical office.
BKA, PKS
Bundeskriminalamt and its Polizeiliche Kriminalstatistik, the police crime statistics.
